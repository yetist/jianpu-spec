# v2.0 与 GB/T 46845—2025 对照及完善记录

> 依据：GB/T 46845—2025《音乐曲谱出版 简谱 通用规范》（2025-12-02 发布，2026-04-01 实施，79 页）。
>
> 说明：GB/T 46845—2025 面向**出版谱面**，规定的是符号形态、功能和使用要求；v2.0 面向**文本输入**，因此对照时关注“标准要求能否被 v2 表达/校验/交给渲染器实现”，不要求逐字复制标准条文。

## 1. 总体结论

v2.0 已经覆盖了简谱出版中最核心的一批符号和结构：音高、八度、时值、休止、变化音、延音线、连音线、多连音、倚音、力度、反复、跳房子、跳转、声部、歌词、拍号/调号/速度、分页与基本排版键。

与国家标准对照后，主要缺口集中在四类：

1. **谱表体式符号**：虚小节线、声部引导线、声部划分号、唱词划分号、辅助连谱号/大谱表/直连谱表的显式表达。
2. **基本符号的完整形态**：重升/重降、八度号、同调移调乐器、辅助变化音、延长号在更多位置上的用法。
3. **反复与序次的细分种类**：小节反复、音型反复、无定次反复、段落序号/小节序号的计数规则。
4. **辅助符号的细分**：震音、表情术语、分句线/音节线/声乐连音线、指法/弓法/弦序/换乐器等表演技术符号。

本次先补齐了其中**能直接进入核心文本语法、且不破坏现有文件**的一部分；其余在本文第 4 节列出建议。

## 2. 本次已补齐或明确的内容

| 标准位置 | 标准对象 | v2 处理 |

## 3. 逐项对照

### 3.1 谱表体式符号（标准第 5 章）

| 标准条款 | v2 现状 | 结论/建议 |
|---|---|---|
| 5.2 小节线与小节 | `\|`、`\|\|`、`\|]`、行首起始小节线、空小节校验 | 基本覆盖；本次补 `\beatbar` |
| 5.2.3 虚小节线 | 原先无 | 本次补 `\beatbar` |
| 5.3 连谱号（连谱线、花连谱号、直连谱号、辅助连谱号） | `@voice bracket=brace/bracket/line` 只能描述行左侧括弧；无系统级连谱号树 | **部分覆盖**。建议增加系统级 `@system`/`@score` 声明，表达“大谱表/直连谱表/辅助连谱号”的嵌套关系 |
| 5.4 谱表种类 | 用系统 + 声部行表达单行/多行 | **部分覆盖**。大谱表、直连谱表、独唱/伴奏谱表缺少显式模型 |
| 5.5 终止线、段落线 | `\|]` 终止线、`\|\|` 双小节线（段落线） | 基本覆盖；`\|]` 已限制在段尾/曲尾，`\|\|` 可再明确“段落线”语义 |
| 5.6 声部引导线 | 无 | **缺口**。建议增加 `\voiceguide(from=..., to=...)` 或由声部行连续性自动推导 |
| 5.7.1 声部划分号 | `\voice` 临时声部块可表达临时分/合，但没有括弧符号 | **部分覆盖**。可在 `\voice` 选项增加 `division=split/merge`，或增加 `\voicesplit`/`\voicemerge` |
| 5.7.2 唱词划分号 | 歌词模型没有“多段共用唱词”的括弧 | **缺口**。建议在歌词行增加 `\lyricgroup{...}` 或 `L: \lyricjoin{...}` |

### 3.2 基本符号（标准第 6 章）

| 标准条款 | v2 现状 | 结论/建议 |
|---|---|---|
| 6.2.1–6.2.4 音高、音高组、高低音点 | `1–7`、`'`、`,` | 覆盖；标准的高/低音组命名属于渲染/排版概念，可在文档补充 |
| 6.2.5 变化音 | `#`、`b`、`n`；本次补 `##`、`bb` | 基本覆盖；**辅助（提醒）变化音**尚未建模，建议增加 `\cautionary` 或 `5(#)` 形式 |
| 6.2.6 八度号 | 本次补 `\ottava` | 基本覆盖；八度重复号（con 8）尚未建模 |
| 6.2.7 各调中音 1 的记谱音位 | `@key 1=C` / `6=A` 表达调号；未规定绝对音位表 | 可在渲染器文档中补充，不影响文本解析 |
| 6.2.8 同调移调乐器 | 本次补 `@voice transpose=8|-8` | 覆盖八度移调；非八度移调乐器仍建议用 `x-` 扩展 |
| 6.2.9 调号 | `@key`、行内 `\key` | 覆盖 |
| 6.3.1–6.3.13 时值、增减时线、附点、休止、延长号、拍号、延音线、时值组合 | `/`、`.`、`-`、`0`、`~`、拍组、多连音 | 基本覆盖；延长号目前主要作为 `\fermata` 记号，标准允许在小节线、换气号上使用，建议在文档明确 |
| 6.3.14 完全/不完全小节 | `@pickup`、`\partial` | 覆盖；小节序号计数规则已补充 |

### 3.3 辅助符号（标准第 7 章）

| 标准条款 | v2 现状 | 结论/建议 |
|---|---|---|
| 7.2 速度 | `@tempo`、行内 `\tempo`、文字速度 | 部分覆盖；建议正式补充 `rit.`、`accel.`、`a tempo` 等**变化速度术语**的文本规则 |
| 7.3 力度 | `\pp`…`\fff`、`\<`、`\>`、`\!`、`\fp` 等 | 部分覆盖；相对力度、图形力度（渐强线）可交给渲染器，但需文档化 |
| 7.4 表情符号 | 本次补 `\expr` | 基本覆盖；常用术语表可后续补充 |
| 7.5 装饰音 | `[]`、`\grace`、`\after`、`\trill`、`\mordent`、`\turn` | 基本覆盖 |
| 7.6 滑音 | `\gliss(up|down)` | 部分覆盖；大滑音、主从滑音、连滑音、经过句等细分尚未建模 |
| 7.7 琶音 | `\arpeggio` | 部分覆盖；建议支持 `\arpeggio(up|down)` 及奏法参数 |
| 7.8 震音 | 本次补 `\trem` / `\tremolo` 记号 | **部分覆盖**；同音高/不同音高震音的时值规则、跨小节标记仍需渲染器实现 |
| 7.9 通用发音符号 | `\stacc`、`\ten`、`\acc`、`\marc` | 基本覆盖；与连线同时使用时的置位规则应写入渲染器要求 |
| 7.10 连线 | `~` 延音线、`( ... )` 连音线、`\phrase` 分句线 | **部分覆盖**；音节线、声乐连音线尚未建模，建议增加 `\syllabaline` 等 |
| 7.11 表演技术符号 | 本次补 `\finger`、`\bow`、`\string`、`\instrument`、`\pitched` | 部分覆盖；换气已有 `\breath`，改换乐器等仅记录提示 |

### 3.4 序次、行款与证实（标准第 5.9、5.11、第 8 章）

- 小节序号：本次补 `\measure-number(n)`，并在正文写明“不完全小节不计、反复内不重复计数”。
- 段落序号/排练号：`\mark("A")` 已覆盖；渲染器应使用较大字号。
- 行款：v2 的 `layout.systems`、`layout.spacing`、`\break` 只覆盖一部分；标准 5.11 的时值占位、纵向对位、附点/连音线对齐属于渲染器职责，建议在 `12.2 渲染器` 中增加一致性要求。
- 证实方法（标准第 8 章）：v2 的解析器测试可承担“符号使用要求”的自动检查；建议后续把标准中的典型正误例做成测试夹具。

## 4. 建议后续补齐（按优先级）

### P0：影响语义或播放

1. **声部引导线**：`\voiceguide(from, to)`，或从声部行连续性自动推导。
2. **音节线/声乐连音线**：与 `~`、`( )`、`\phrase` 区分的独立 span。
3. **辅助变化音（提醒变音号）**：建议 `\cautionary` 记号，渲染为带括号的 `#/b/n`。
4. **八度重复号**：`\ottava(up, repeat)` 或 `\con8`，表示平行八度。
5. **小节/音型/无定次反复**：在 `\repeatprev` 基础上补 `\figrepeat`、`\repeat(forever)` 或 `x-repeat-*`。

### P1：出版谱面完整性

1. **系统级连谱号树**：`@system`/`@score` 描述大谱表、直连谱表、辅助连谱号。
2. **声部划分号/唱词划分号**：`\voicesplit`/`\voicemerge`、`\lyricgroup`。
3. **滑音/琶音/震音细分参数**：`\gliss(kind=...)`、`\arpeggio(up|down)`、`\trem(count=...)`。
4. **速度/表情术语表**：`\tempo("rit.")`、`\expr("dolce")` 的常用术语与置位规则。

### P2：排版与测试

1. 按标准 5.11 增加“时值占位/纵向对位”的渲染器测试。
2. 按标准第 8 章建立正误例夹具，覆盖变化音、延音线、八度号、反复等。
3. 增加 `@layout.measure-numbers` 与 `\measure-number` 的冲突检测。

## 5. 兼容性

- 本次新增语法均为**增量**：现有 v2 文件不需要修改。
- `##`/`bb` 只在音符修饰符位置解析，不会与歌词、注释或其他上下文冲突。
- `\beatbar`、`\ottava`、`\repeatprev`、`\measure-number` 都是新的标准命令；旧解析器遇到会报未知命令，符合版本升级预期。
- `@voice transpose=` 是新的可选选项；旧文件不受影响。
