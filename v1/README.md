```sh
# 在源文件旁生成 <name>.v2.jps 和 <name>.v2.report.txt
bin/jps1to2.py <file.jps>
```

转换器按 [v2.0 迁移指南](../v2/02-v1迁移指南.md) 工作，输出中的 `% TODO:` 和报告文件需要人工复核。
